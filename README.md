# Number-Series  
Collection of number-series and number-theory routines written in C

## Overview  
This repository houses a variety of standalone C programs that compute and demonstrate well-known number series and number-theory sequences. Each program is simple, experiment with or extend fundamental mathematical algorithms in C.

## What’s included  
Each `.c` file corresponds to one sequence or concept. Some examples:

- `fibonacci.c` – Fibonacci sequence  
- `prime.c` – Prime number detection  
- `armstrong.c` – Armstrong (narcissistic) number check  
- `triangular.c` – Triangular numbers 
- …and more.

## Features  
- Written entirely in C.
- Isolated programs — compile and run each one individually.
